### ✅ 2. Câu mẫu thực tế

| Câu hỏi phỏng vấn kỹ thuật                                           | Câu trả lời mẫu (rút gọn – có thể mở rộng)                                                                                                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "What is the difference between a stack and a queue?"                | A stack uses LIFO (last in, first out), while a queue uses FIFO (first in, first out).                                                                                    |
| "Can you explain Big-O notation?"                                    | Big-O describes the time or space complexity of an algorithm. For example, a linear search has O(n), while binary search has O(log n).                                    |
| "Describe a time you debugged a hard problem."                       | I once faced a bug that only appeared on mobile. I used logs and binary search within the code to isolate the issue and found it was caused by an uninitialized variable. |
| "What’s the difference between pass-by-value and pass-by-reference?" | Pass-by-value creates a copy of the variable. Pass-by-reference passes the memory address, so changes affect the original.                                                |

### ✅ 3. Bài luyện viết ✍️

**Đề bài:**
Viết một đoạn mô tả cách bạn giải quyết một bài toán kỹ thuật bạn từng gặp. (6–8 câu)

**Gợi ý bố cục:**

* Mô tả vấn đề kỹ thuật
* Bạn đã tiếp cận ra sao?
* Công cụ hoặc phương pháp bạn dùng?
* Kết quả ra sao?

**Ví dụ:**

```
I once worked on optimizing a function that loaded thousands of game assets. It caused lag on low-end devices. I profiled the function and saw that it was running synchronously. I rewrote it using asynchronous loading and batching. After testing, the frame rate improved by 30%. This experience taught me the importance of profiling before optimizing.
```

### ✅ 4. Bài luyện nói 🎤

**Câu hỏi luyện nói mô phỏng phỏng vấn kỹ thuật:**

1. Can you walk me through how you would debug a null pointer error?
2. How would you design a system to handle thousands of user logins per second?
3. What’s the difference between an abstract class and an interface?
4. How do you approach optimizing game performance?
5. Describe a technical challenge you faced and how you overcame it.

🎯 *Gợi ý:* Trả lời trong 60–90 giây. Cấu trúc nên gồm: Mở đầu vấn đề → Giải thích giải pháp → Nêu kết quả hoặc bài học.

### ✅ 5. Ghi chú mở rộng

#### 📌 Kỹ năng khi trả lời câu hỏi kỹ thuật:

| Kỹ năng                      | Mẹo thực tế                                                                  |
| ---------------------------- | ---------------------------------------------------------------------------- |
| Giải thích rõ ràng           | Tránh dùng quá nhiều từ chuyên ngành nếu không cần thiết                     |
| Nêu lý do lựa chọn giải pháp | “I chose this method because it’s more scalable / easier to maintain.”       |
| Thành thật nếu không biết    | “I haven’t used that directly, but I’m familiar with similar concepts like…” |
| Phân tích trade-off          | “This solution is faster but uses more memory.”                              |

#### 📌 Các chủ đề kỹ thuật thường được hỏi:

* Dữ liệu & thuật toán: sorting, searching, hash maps, trees
* Kiến trúc phần mềm: MVC, design patterns
* Kỹ thuật debug & tối ưu hóa
* Câu hỏi về ngôn ngữ cụ thể (JavaScript, Python, C++, v.v.)
* Viết code trực tiếp (online whiteboard hoặc trình biên dịch)
