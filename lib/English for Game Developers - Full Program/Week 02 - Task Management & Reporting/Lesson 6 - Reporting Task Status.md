# ✅ Lesson 6 – Reporting Task Status

> 📘 **Mục tiêu bài học:**

* ✅ Học cách sử dụng từ vựng, cụm động từ để báo cáo tiến độ công việc.
* ✅ Luyện tập mô tả trạng thái task (hoàn thành, đang làm, bị chặn…).
* ✅ Tự tin cập nhật task trong họp nhóm hoặc báo cáo với quản lý.

---

## 🗣️ Câu mẫu thực tế

### 1. Báo cáo tiến độ:

* **This task is currently in progress.**
* I’ve completed the feature implementation, but it’s still in review.
* The task is **on track** and should be done by tomorrow.

### 2. Trình bày vấn đề:

* This task is **blocked** due to API changes.
* We’re **behind schedule** because of unexpected bugs.
* The issue is **pending** further discussion with the product team.

### 3. Tổng hợp tình hình:

* So far, we’ve **finished 80% of the sprint goals**.
* Everything is going **according to plan**.
* We’re slightly delayed, but I’m working to **catch up**.

---

## ✍️ Bài luyện viết (Writing Practice)

> Viết đoạn cập nhật tiến độ cho 2–3 task bạn đang làm gần đây.

**Gợi ý cấu trúc:**

> Task A is \_\_\_. I’ve already \_\_\_. However, \_\_\_.
> Task B is \_\_\_. It’s currently \_\_\_. I expect to finish it by \_\_\_.

**Ví dụ:**

> Task 1 is in progress. I’ve already completed most of the logic, but the UI part is pending feedback.
> Task 2 is blocked due to a missing API. I’m waiting for the backend team to provide the endpoint.
> I expect both tasks to be done by Friday if things go smoothly.

---

## 🎤 Bài luyện nói (Speaking Practice)

> Luyện trả lời các câu hỏi ngắn như khi tham gia daily standup hoặc report:

1. What are you working on today?
2. Any blockers?
3. What did you complete yesterday?
4. Is your task on track?
5. When do you expect to finish it?

💡 *Tip:* Câu trả lời ngắn gọn, rõ ràng và trung thực là chìa khóa trong môi trường kỹ thuật.

---

## 🧠 Ghi chú mở rộng

* Dạng câu hay dùng trong daily standup:

  * “Yesterday I…”
  * “Today I’m working on…”
  * “I’m blocked by…”

* Các trạng thái task phổ biến:

  * ✅ Done
  * 🔄 In progress
  * ⏳ Pending
  * ❌ Blocked
  * ⌛ Delayed

* Cách chuyển trạng thái trong các công cụ như Jira, Trello, Asana:

  * Move to "In Progress" → Bắt đầu làm
  * Move to "Done" → Hoàn thành
  * Add comment → Thêm ghi chú báo cáo
