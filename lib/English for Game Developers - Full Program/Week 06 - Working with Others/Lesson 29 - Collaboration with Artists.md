# ✅ Lesson 29 – Collaboration with Artists

> 📘 **Mục tiêu bài học:**

* ✅ Giao tiếp hiệu quả với họa sĩ 2D/3D trong quy trình làm game/app.
* ✅ Sử dụng đúng từ vựng khi mô tả yêu cầu, feedback và quy trình tích hợp art.
* ✅ Thực hành viết và nói với tình huống thực tế.

## 🗣️ Câu mẫu thực tế

### A. Yêu cầu tài nguyên:

* Could you export the sprite sheet at **2x resolution**?
* Please send the background as a **separate layer**.
* Do you have a **transparent PNG version** of the icon?

### B. Feedback:

* The animation is smooth, but the transition feels **too fast**.
* Could we make the color scheme more **consistent** with the UI?
* The lighting on this character is a bit **too dark** for our game.

### C. Phối hợp kỹ thuật - mỹ thuật:

* We need the assets to be optimized for **WebGL**.
* Can you provide the **pivot points** for each sprite?
* The file size is too large; maybe we can **compress the textures**?

## ✍️ Bài luyện viết (Writing Practice)

> Viết đoạn tin nhắn/email yêu cầu điều chỉnh asset:

**Mẫu:**

```text
Hi [Artist’s Name],

Thanks for sharing the updated assets – they look fantastic!

Just a quick note: the main character’s animation plays a bit too fast in-game. Could you slow it down slightly or give us a few more frames for the transition?

Also, please send the sprite sheet as a PNG with transparent background if possible.

Thanks a lot!

Best,  
[Your Name]
```

---

## 🎤 Bài luyện nói (Speaking Practice)

> Thực hành trình bày tình huống sau:

1. Bạn cần ảnh nền ở độ phân giải cao hơn.
2. Nhân vật chưa được scale đúng tỉ lệ.
3. Gợi ý thay đổi màu sắc để phù hợp theme game.

**Ví dụ thoại:**

> “Hi, the background looks great, but could we get it in higher resolution? Also, the character seems a bit too small compared to other assets — can we scale it up by 20%? Lastly, maybe we can adjust the palette to match the darker theme of our game?”

---

## 🧠 Ghi chú mở rộng

### 🛠 Quy trình phối hợp hiệu quả:

1. **Concept approval** – Thảo luận idea, style.
2. **Asset creation** – Họa sĩ vẽ và gửi bản nháp hoặc final.
3. **Integration test** – Dev tích hợp vào game/app.
4. **Feedback loop** – Sửa lỗi, tinh chỉnh frame, scale.
5. **Final delivery** – Handover đầy đủ định dạng (PNG, PSD, Spine...).

### ✅ Gợi ý:

* Thỏa thuận trước: kích thước, định dạng, layer, naming convention.
* Dùng công cụ hỗ trợ như: **Figma, Spine, TexturePacker, Lottie**.
* Ưu tiên tổ chức thư mục rõ ràng: `/assets/characters/main_hero_idle.png`
