# ✅ Lesson 23 – Retrospective Meetings

> 📘 **Mục tiêu bài học:**

* ✅ Hiểu từ vựng và mẫu câu dùng trong họp retrospective (xem lại sprint).
* ✅ Học cách đưa ra phản hồi tích cực và xây dựng.
* ✅ Luyện viết và nói trong ngữ cảnh Agile/Scrum team.

## 🗣️ Câu mẫu thực tế

### A. Mở đầu cuộc họp retrospective:

* Let's start our **retrospective** by reviewing what went well and what didn’t.
* This meeting is about **learning and improving**, not blaming.

### B. Góp ý & phản hồi:

* One thing that went well was our communication during the sprint.
* I think we could **improve** how we handle last-minute changes.
* Here’s my **constructive feedback**: let’s write clearer documentation next time.

### C. Hành động & cải tiến:

* We should make it an **action item** to automate the deployment process.
* I’ll **take responsibility** for setting up the new Jira board.

## ✍️ Bài luyện viết (Writing Practice)

> Viết một đoạn email follow-up sau cuộc họp retrospective:

**Mẫu:**

```
Subject: Retrospective Summary – Sprint 12

Hi team,

Thanks for joining today’s retrospective.  
✅ What went well: Clear communication, early bug fixing.  
🔧 To improve: Sprint planning clarity, late testing.  
📌 Action Items:  
– Anna: update QA checklist  
– Minh: review test coverage tools  
– Long: monitor deployment time

Let’s keep improving!

Best,  
[Your Name]
```

---

## 🎤 Bài luyện nói (Speaking Practice)

> Tình huống: Bạn đang nói trong buổi retrospective.

**Gợi ý đoạn nói:**

```
I think one thing we did well was team communication.  
However, we had some blockers due to unclear requirements.  
Next sprint, we should clarify the user stories earlier.  
One action item I’d suggest is setting up a shared document before sprint planning.
```

## 🧠 Ghi chú mở rộng

### 🔹 Cấu trúc thường dùng trong retrospective:

| Phần                  | Ví dụ câu mẫu                                 |
| --------------------- | --------------------------------------------- |
| ✅ What went well      | "Code review process improved a lot."         |
| ❌ What didn’t go well | "Testing was rushed due to time constraints." |
| 🛠️ Action items      | "Schedule earlier QA handoff."                |

### 🔹 Cách đưa ra phản hồi:

* **Tốt:** “I liked how you supported the new member.”
* **Cải tiến:** “Next time, we can clarify roles earlier.”
