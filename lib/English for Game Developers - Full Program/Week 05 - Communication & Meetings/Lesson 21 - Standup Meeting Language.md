# ✅ Lesson 21 – Standup Meeting Language

> 📘 **Mục tiêu bài học:**

* ✅ Học từ vựng & cụm từ thường dùng trong cuộc họp standup.
* ✅ Thực hành nói về: việc đã làm, đang làm, và kế hoạch tiếp theo.
* ✅ Cách diễn đạt blocker, delay, và dependency rõ ràng bằng tiếng Anh.

---

## 🗣️ Câu mẫu thực tế

### 1. Nói về việc đã làm:

* Yesterday, I **completed** the user login screen.
* I **finished** refactoring the player movement logic.

### 2. Việc đang làm:

* I'm **currently working on** the leaderboard integration.
* I'm fixing a bug related to scene transitions.

### 3. Việc sắp làm:

* Next, I'll start implementing the save/load system.
* I plan to work on UI polishing today.

### 4. Vấn đề gặp phải:

* I'm **blocked** by a missing asset from the design team.
* I'm still **waiting for** feedback from QA.
* This task is **delayed** due to a dependency on backend changes.

---

## ✍️ Bài luyện viết (Writing Practice)

> Viết một đoạn cập nhật standup bằng tiếng Anh:

**Gợi ý mẫu:**

```
Yesterday, I finished the player controller script.  
Today, I'm working on the enemy AI.  
Tomorrow, I'll test collision detection.  
I'm blocked by missing animations from the art team.
```

---

## 🎤 Bài luyện nói (Speaking Practice)

> Trả lời 3 câu hỏi thường gặp trong standup, bằng giọng rõ ràng:

1. What did you do yesterday?
2. What are you working on today?
3. Are there any blockers?

**Gợi ý trả lời:**

* "Yesterday, I fixed the performance issue on mobile devices."
* "Today, I'm working on setting up analytics."
* "I'm blocked by an environment setup issue."

---

## 🧠 Ghi chú mở rộng

### 🔹 Mẫu kịch bản standup (theo format 3 phần)

```
🟢 What I did yesterday:  
- Finished implementing the pause menu.

🟡 What I’m doing today:  
- Working on integrating ads via Facebook Audience Network.

🔴 Blockers:  
- Waiting for access to the production API.
```

### ✏️ Tips khi nói trong standup:

* Luôn trả lời ngắn gọn, tập trung vào output.
* Đừng trình bày lý do dài dòng nếu không ai hỏi.
* Dùng thì hiện tại đơn & tiếp diễn (Present Simple + Continuous).
