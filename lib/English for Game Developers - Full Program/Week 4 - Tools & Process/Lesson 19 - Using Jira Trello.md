# ✅ Lesson 19 – Using Jira & Trello

> 📘 **Mục tiêu bài học:**

* ✅ Làm quen với các thuật ngữ quản lý công việc bằng tiếng Anh.
* ✅ Biết cách mô tả và cập nhật trạng thái task trên công cụ như Jira hoặc Trello.
* ✅ Tự tin giao tiếp khi thảo luận backlog, task priority, và workflow.

## 🗣️ Câu mẫu thực tế

### 1. Mô tả công việc:

* I just created a **new ticket** in Jira for the login bug.
* This task is currently **in progress**.
* We usually **assign** tasks during sprint planning.

### 2. Về quy trình và quản lý:

* We move tasks across columns on the **Kanban board**.
* Each task has a **priority level** and an **estimated time**.
* I updated the status of the task to **Done**.

### 3. Về công cụ:

* I prefer Trello for smaller projects and Jira for larger teams.
* Jira helps us manage complex **workflows** with different issue types.

## ✍️ Bài luyện viết (Writing Practice)

> Viết đoạn mô tả ngắn (5–7 câu) về cách bạn sử dụng Jira hoặc Trello tại công ty:

**Gợi ý:**

> At our company, we use Jira to manage all tasks and bugs.
> Every Monday, we have sprint planning and assign tasks.
> I usually work on tasks labeled as "In Progress" or "To Do".
> After finishing, I update the ticket status to "Done" and leave a comment.
> We also estimate the effort using story points.

---

## 🎤 Bài luyện nói (Speaking Practice)

> Trả lời các câu hỏi sau bằng tiếng Anh:

1. What task management tool does your team use?
2. How do you track progress on your tasks?
3. Can you describe the Jira (or Trello) workflow you follow?

**Gợi ý mở đầu:**

* “We use Trello to track progress in small teams…”
* “Our board has three columns: To Do, In Progress, and Done…”
* “I update task status daily and comment if I’m blocked…”

## 🧠 Ghi chú mở rộng

### 🧩 Các loại "issue" trong Jira:

* `Story` – Tính năng chính cần thực hiện
* `Task` – Việc cụ thể nhỏ hơn
* `Bug` – Lỗi cần sửa
* `Sub-task` – Việc con của task chính
* `Epic` – Nhóm các stories lớn

### 📌 Các trạng thái phổ biến:

| Trạng thái  | Ý nghĩa               |
| ----------- | --------------------- |
| To Do       | Chưa bắt đầu          |
| In Progress | Đang thực hiện        |
| Code Review | Chờ được review       |
| Blocked     | Đang bị chặn          |
| Done        | Đã hoàn thành         |
| Won’t Do    | Bỏ qua, không làm nữa |
