# ✅ Lesson 20 – Writing Documentation

> 📘 **Mục tiêu bài học:**

* ✅ Biết cách sử dụng từ vựng mô tả tài liệu kỹ thuật bằng tiếng Anh.
* ✅ Thực hành viết tài liệu đơn giản: README, hướng dẫn sử dụng, technical spec.
* ✅ Tự tin nói về tầm quan trọng và cách viết tài liệu rõ ràng.

## 🗣️ Câu mẫu thực tế

### 1. Giới thiệu tài liệu:

* Please refer to the **README file** for setup instructions.
* The documentation is available on our internal wiki.
* We wrote a detailed **API reference** for other teams.

### 2. Về cách viết tài liệu:

* Try to write your docs with **clarity** and structure.
* Keep the documentation **up to date** with code changes.
* Use **code comments** to explain complex logic.

### 3. Mô tả quy trình:

* We maintain technical specifications in Confluence.
* The QA team follows the **user manual** during testing.
* Documentation is part of our **definition of done**.

## ✍️ Bài luyện viết (Writing Practice)

> Viết một đoạn README ngắn cho một game hoặc project bạn từng làm:

**Gợi ý nội dung:**

```markdown
# Space Invaders Clone

This is a simple 2D shooting game built with Cocos Creator.

## How to Run
1. Clone the repo
2. Open in Cocos Creator
3. Click "Play"

## Features
- Infinite enemies
- Score tracking
- Responsive controls

## Requirements
- Cocos Creator 3.x
```

## 🎤 Bài luyện nói (Speaking Practice)

> Trả lời các câu hỏi sau bằng tiếng Anh:

1. Do you usually write documentation? What kind?
2. What are the common types of documents in your current or previous team?
3. Why do you think good documentation is important?

**Gợi ý mở đầu:**

* "In my previous team, we had technical specs and user guides for every release."
* "I usually write README files for personal projects."
* "Documentation helps new developers understand the system faster."

## 🧠 Ghi chú mở rộng

### 🔹 Các loại tài liệu thường gặp trong phát triển phần mềm:

| Loại tài liệu           | Mục đích                                                       |
| ----------------------- | -------------------------------------------------------------- |
| README                  | Giới thiệu dự án, hướng dẫn cài đặt nhanh                      |
| API Reference           | Chi tiết hàm, endpoint, tham số – dùng cho lập trình viên khác |
| Technical Specification | Mô tả chi tiết tính năng, logic, kiến trúc                     |
| User Manual             | Hướng dẫn cho người dùng cuối                                  |
| Architecture Document   | Mô hình hệ thống, diagram luồng dữ liệu, quy trình xử lý chính |

### ✏️ Mẹo viết tài liệu hiệu quả:

* Dùng tiêu đề rõ ràng (Heading H2, H3…)
* Có ví dụ cụ thể, copy-paste được
* Dùng câu đơn giản, tránh dùng bị động nếu không cần thiết
