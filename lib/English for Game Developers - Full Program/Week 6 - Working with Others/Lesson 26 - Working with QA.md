# ✅ Lesson 26 – Working with QA

> 📘 **Mục tiêu bài học:**

* ✅ Học từ vựng và mẫu câu thường dùng khi làm việc với QA.
* ✅ Thực hành mô tả bug, tình huống test, và trao đổi trong quá trình kiểm thử.
* ✅ Cải thiện kỹ năng viết và nói khi tương tác với QA team.

---

## 📚 Từ vựng chính (IPA + nghĩa)

| Từ / Cụm từ            | Phiên âm IPA            | Nghĩa tiếng Việt                  |
| ---------------------- | ----------------------- | --------------------------------- |
| bug                    | /bʌɡ/                   | lỗi                               |
| reproduce (a bug)      | /ˌriː.prəˈdjuːs/        | tái hiện lỗi                      |
| test case              | /tɛst keɪs/             | kịch bản kiểm thử                 |

## 🗣️ Câu mẫu thực tế

### A. Khi mô tả lỗi với QA:

* The bug happens when I click the "Start" button after login.
* Can you try to **reproduce** it on your side?
* It only appears in the staging **test environment**.

### B. Khi trao đổi về mức độ ưu tiên:

* This is a high **severity** bug; it blocks the login flow.
* It’s not critical, so we can fix it in the next **deployment**.
* Let’s prioritize the **regression** bugs first.

### C. Phản hồi khi QA hỏi:

* Yes, I’ve pushed a hotfix to staging for testing.
* I’ve updated the **checklist** for that scenario.
* Please test it again with the latest version.

## ✍️ Bài luyện viết (Writing Practice)

> Viết đoạn chat gửi QA sau khi bạn fix xong một bug:

**Mẫu:**

```
Hi [QA Name],

I’ve fixed the issue with the score not updating correctly.  
You can test it now in the staging environment (version 1.2.3).  
Let me know if it’s still reproducible.

Thanks!
```

## 🎤 Bài luyện nói (Speaking Practice)

> Tình huống: QA báo lỗi nhưng bạn không tái hiện được.

**Mẫu hội thoại:**

```
QA: I found a bug when switching scenes.

Dev (you): I see. I tried it several times but couldn’t reproduce it.  
Can you send me the exact steps and the device you tested on?

QA: Sure. I’ll attach a screen recording.

Dev: Great, that’ll help a lot. Thanks!
```

## 🧠 Ghi chú mở rộng

### ✅ Mức độ **Severity vs. Priority**

* **Severity**: mức độ nghiêm trọng của lỗi với chức năng.
* **Priority**: mức độ cần sửa nhanh đến đâu.

| Severity | Priority | Ý nghĩa                           |
| -------- | -------- | --------------------------------- |
| Critical | High     | Lỗi nặng, cần sửa gấp             |
| Medium   | Medium   | Có thể sửa ở bản tiếp theo        |
| Low      | Low      | Không ảnh hưởng, để sau cũng được |

### ✅ Cụm từ hay dùng:

* “Can you help verify this on your end?”
* “It’s working as expected now.”
* “Let’s close this ticket if everything looks good.”
