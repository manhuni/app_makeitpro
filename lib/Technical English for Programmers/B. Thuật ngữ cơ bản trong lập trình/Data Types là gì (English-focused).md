# 07 – Data Types là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Hiểu và sử dụng các thuật ngữ tiếng Anh về kiểu dữ liệu (data types)
* Luyện phát âm chuẩn với IPA
* Sử dụng đúng từ vựng trong giao tiếp và viết mô tả kỹ thuật

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ | IPA (Phát âm)  | Nghĩa tiếng Việt           | Ghi chú thêm                            |
| ----------- | -------------- | -------------------------- | --------------------------------------- |
| data type   | /ˈdeɪtə taɪp/  | kiểu dữ liệu               | Kiểu của dữ liệu mà biến lưu trữ        |
| string      | /strɪŋ/        | chuỗi                      | Dữ liệu dạng văn bản                    |
| number      | /ˈnʌm.bər/     | số                         | Gồm số nguyên, số thực                  |
| boolean     | /ˈbuː.li.ən/   | kiểu đúng/sai (true/false) | Có hai giá trị: true hoặc false         |
| undefined   | /ˌʌn.dɪˈfaɪnd/ | chưa xác định              | Biến chưa có giá trị                    |
| null        | /nʌl/          | giá trị rỗng               | Đại diện cho “không có gì”              |
| object      | /ˈɒb.dʒɪkt/    | đối tượng                  | Cấu trúc chứa nhiều giá trị (key–value) |
| array       | /əˈreɪ/        | mảng                       | Danh sách có thứ tự gồm nhiều phần tử   |

---

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                                | Dịch tiếng Việt                           |
| -------------------------------------------- | ----------------------------------------- |
| What data type is this variable?             | Biến này thuộc kiểu dữ liệu gì?           |
| A string holds text data.                    | Chuỗi chứa dữ liệu dạng văn bản.          |
| Boolean values are either `true` or `false`. | Giá trị boolean là `true` hoặc `false`.   |
| The function returned `undefined`.           | Hàm trả về `undefined`.                   |
| We use arrays to store multiple values.      | Chúng tôi dùng mảng để lưu nhiều giá trị. |

---

## 📚 Ví dụ minh họa

```javascript
let name = "Alice";       // string
let age = 30;             // number
let isOnline = true;      // boolean
let address = null;       // null
let result;               // undefined
let scores = [10, 20, 30]; // array
let user = { name: "Bob", age: 25 }; // object
```

---

## 💬 Hội thoại mẫu

> 👨‍💻 **A:** What’s the data type of `isLoading`?
> 👩‍💻 **B:** It’s a boolean. It’s set to `true`.
> 👨‍💻 **A:** And `userName`?
> 👩‍💻 **B:** That’s a string — `"John"`.

---

## ✅ Bài tập nhanh

Điền từ còn thiếu:

1. `"hello"` is a \_\_\_\_\_\_\_\_\_.
2. `true` and `false` are \_\_\_\_\_\_\_\_ values.
3. A variable with no value is `_________`.
4. We use `_________` to group multiple values in order.

> Đáp án: 1) string, 2) boolean, 3) undefined, 4) array

---

## ✍️ Thực hành viết

Viết đoạn mô tả ngắn (2–3 câu) về kiểu dữ liệu của các biến sau:

```javascript
let name = "Tuan";
let age = 20;
let isStudent = false;
```

Ví dụ viết bằng tiếng Anh:

> The variable `name` is a string. It stores text.
> `age` is a number. `isStudent` is a boolean, with the value `false`.

---

* Phát âm đúng sẽ giúp bạn **giao tiếp chuyên nghiệp** hơn
* Sử dụng từ vựng này thường xuyên để ghi nhớ tự nhiên
