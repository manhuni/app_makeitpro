# 10 – Objects & Arrays là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Làm quen với từ vựng tiếng Anh chuyên ngành về **đối tượng (object)** và **mảng (array)**
* Luyện phát âm, mẫu câu, và hội thoại thực tế về dữ liệu phức tạp
* Viết mô tả kỹ thuật đơn giản bằng tiếng Anh

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ    | IPA                  | Nghĩa tiếng Việt  | Ghi chú thêm                                 |
| -------------- | -------------------- | ----------------- | -------------------------------------------- |
| object         | /ˈɒbdʒɪkt/           | đối tượng         | Dữ liệu có cấu trúc (key–value pairs)        |
| array          | /əˈreɪ/              | mảng              | Danh sách có thứ tự                          |
| property       | /ˈprɒpəti/           | thuộc tính        | Key trong object                             |
| value          | /ˈvæljuː/            | giá trị           | Dữ liệu gắn với key hoặc phần tử mảng        |
| key-value pair | /kiː ˈvæljuː peə(r)/ | cặp khóa-giá trị  | Cấu trúc cơ bản trong object                 |
| index          | /ˈɪndeks/            | chỉ số (của mảng) | Vị trí của phần tử trong mảng (bắt đầu từ 0) |

---

## 📚 Ví dụ minh họa

### Object Example

```javascript
const user = {
  name: "Anna",
  age: 28,
  isOnline: true
};
```

### Array Example

```javascript
const fruits = ["apple", "banana", "orange"];
```

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                          | Dịch tiếng Việt                                  |
| -------------------------------------- | ------------------------------------------------ |

| This array holds a list of products.   | Mảng này chứa danh sách sản phẩm.                |
| Each object has several properties.    | Mỗi object có một số thuộc tính.                 |
| Access the array item using its index. | Truy cập phần tử mảng bằng chỉ số của nó.        |

## 💬 Hội thoại mẫu

> 👨‍💻 **A:** What's inside this array?
> 👩‍💻 **B:** It's a list of user IDs.
> 👨‍💻 **A:** Got it. And this object?
> 👩‍💻 **B:** It stores user info like name and age.

---

## ✅ Bài tập nhanh

Điền từ còn thiếu:

1. An \_\_\_\_\_\_\_ is a list of items.
2. An \_\_\_\_\_\_\_ uses key-value pairs.
3. We access a property of an object using a \_\_\_\_\_\_\_.
4. We access an array item using an \_\_\_\_\_\_\_.

> **Đáp án:** 1) array, 2) object, 3) key, 4) index

---

## ✍️ Thực hành viết

Viết mô tả ngắn bằng tiếng Anh cho đoạn code sau:

```javascript
const car = {
  brand: "Toyota",
  year: 2020,
  color: "red"
};

const colors = ["red", "green", "blue"];
```

**Gợi ý mẫu câu:**

> The `car` object has three properties: brand, year, and color.
> The `colors` array contains three values: "red", "green", and "blue".

---

## 📌 Ghi nhớ

* **Objects** là cấu trúc dữ liệu có dạng `{ key: value }`
* **Arrays** là danh sách dữ liệu truy cập qua **index**
* Phân biệt rõ cách dùng và từ vựng đi kèm giúp giao tiếp hiệu quả hơn
