# 06 – Variable là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Hiểu từ vựng "variable" và các thuật ngữ liên quan bằng tiếng Anh
* Luyện phát âm, ghi nhớ từ chuyên ngành qua ví dụ thực tế
* Giao tiếp và viết về biến trong môi trường làm việc bằng tiếng Anh

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ        | Phiên âm (IPA)           | Nghĩa tiếng Việt | Ghi chú thêm                        |
| ------------------ | ------------------------ | ---------------- | ----------------------------------- |
| variable           | /ˈveəriəbl/              | biến             | Tên đại diện cho dữ liệu trong code |
| declare a variable | /dɪˈkleə(r) ə ˈveəriəbl/ | khai báo biến    | declare = khai báo                  |
| assign a value     | /əˈsaɪn ə ˈvæljuː/       | gán giá trị      | Gán dữ liệu cho biến                |
| constant           | /ˈkɒnstənt/              | hằng số          | Biến không thay đổi                 |
| data type          | /ˈdeɪtə taɪp/            | kiểu dữ liệu     | Ví dụ: string, number, boolean      |

---

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                                       | Dịch tiếng Việt                                  |
| --------------------------------------------------- | ------------------------------------------------ |
| I declared a variable named `age`.                  | Tôi đã khai báo một biến tên là `age`.           |
| You should use `const` if the value doesn't change. | Bạn nên dùng `const` nếu giá trị không thay đổi. |
| What data type is this variable?                    | Biến này thuộc kiểu dữ liệu gì?                  |
| Can you assign a new value to that variable?        | Bạn có thể gán giá trị mới cho biến đó không?    |

---

## 🗣️ Phát âm luyện nói

Luyện nói các cụm sau:

* "variable" → /ˈveəriəbl/
* "assign a value" → /əˈsaɪn ə ˈvæljuː/
* "declare a variable" → /dɪˈkleə(r) ə ˈveəriəbl/
* "constant" → /ˈkɒnstənt/

🎧 *Tip: Ghi âm giọng bạn để nghe lại và chỉnh phát âm.*

---

## 💬 Mẫu hội thoại ngắn

> 👩‍💻 **A:** What’s the difference between a variable and a constant?
> 👨‍💻 **B:** A variable can change. A constant stays the same.
> 👩‍💻 **A:** Got it! So I’ll use `const` for fixed values.
> 👨‍💻 **B:** Exactly!

---

## 🧠 Thực hành từ vựng

Điền từ thích hợp:

1. I always use `_______` to declare variables in JavaScript.
2. A `_______` cannot be reassigned.
3. The `_______` of `name` is a string.

> ✅ Đáp án: 1) let / const, 2) constant, 3) data type

---

## ✍️ Viết thử (Writing Practice)

Viết 3 câu giới thiệu về biến trong tiếng Anh, ví dụ:

* I created a variable called `score`.
* It stores a number.
* Later, I assigned it a new value.

---

## 📌 Ghi nhớ

* "variable" là từ khóa rất phổ biến trong lập trình
* Phát âm là /ˈveəriəbl/ – không phải “ve-ri-a-bồ” 😄
* Hãy dùng từ vựng này khi nói/viết về code với đồng nghiệp quốc tế
