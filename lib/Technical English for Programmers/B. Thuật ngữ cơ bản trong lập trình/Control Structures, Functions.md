# 08 – Control Structures là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Hiểu và sử dụng từ vựng tiếng Anh về **cấu trúc điều khiển (control structures)**
* Nắm được cách diễn đạt các hành động điều kiện, lặp, nhánh trong code
* Luyện nghe, nói, đọc, viết các thuật ngữ phổ biến

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ       | IPA                      | Nghĩa tiếng Việt    | Ghi chú                    |
| ----------------- | ------------------------ | ------------------- | -------------------------- |
| control structure | /kənˈtrəʊl ˈstrʌktʃə(r)/ | cấu trúc điều khiển | Gồm if, loop, switch, etc. |
| conditional       | /kənˈdɪʃənl/             | điều kiện           | if, else, else if          |
| loop              | /luːp/                   | vòng lặp            | for, while, do…while       |
| if statement      | /ɪf ˈsteɪtmənt/          | câu lệnh if         | Kiểm tra điều kiện         |
| for loop          | /fɔː(r) luːp/            | vòng lặp for        | Lặp theo số lần xác định   |
| while loop        | /waɪl luːp/              | vòng lặp while      | Lặp khi điều kiện đúng     |
| switch statement  | /swɪtʃ ˈsteɪtmənt/       | câu lệnh switch     | Kiểm nhiều điều kiện       |

---

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                                       | Dịch tiếng Việt                          |
| --------------------------------------------------- | ---------------------------------------- |
| Use an if statement to check the condition.         | Dùng câu lệnh if để kiểm tra điều kiện.  |
| The loop runs five times.                           | Vòng lặp chạy 5 lần.                     |
| A switch statement is cleaner for multiple options. | Switch dễ đọc hơn khi có nhiều lựa chọn. |

---

## 📚 Ví dụ minh họa

```javascript
let score = 85;

if (score >= 90) {
  console.log("Excellent!");
} else if (score >= 75) {
  console.log("Good job!");
} else {
  console.log("Keep trying.");
}
```

---

## 🗣️ Luyện phát âm

* "conditional" → /kənˈdɪʃənl/
* "loop" → /luːp/
* "switch" → /swɪtʃ/
* "statement" → /ˈsteɪtmənt/

---

## 💬 Hội thoại mẫu

> 👩‍💻 **A:** Should I use an if or a switch here?
> 👨‍💻 **B:** If there are many conditions, go with switch.
> 👩‍💻 **A:** Got it! Thanks.

# 09 – Functions là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Hiểu khái niệm **function (hàm)** qua tiếng Anh chuyên ngành
* Giao tiếp về việc định nghĩa, gọi, và truyền tham số trong hàm
* Làm quen với từ vựng liên quan đến xử lý logic bằng hàm

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ     | IPA               | Nghĩa tiếng Việt        | Ghi chú thêm                   |
| --------------- | ----------------- | ----------------------- | ------------------------------ |
| function        | /ˈfʌŋkʃn/         | hàm                     | Khối mã có thể tái sử dụng     |
| parameter       | /pəˈræmɪtə(r)/    | tham số (đầu vào hàm)   | Khai báo trong function        |
| argument        | /ˈɑːɡjumənt/      | đối số (truyền vào hàm) | Giá trị truyền vào khi gọi hàm |
| return value    | /rɪˈtɜːn ˈvæljuː/ | giá trị trả về          | Output của hàm                 |
| call a function | /kɔːl ə ˈfʌŋkʃn/  | gọi một hàm             |                                |

---

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                               | Dịch tiếng Việt                 |
| ------------------------------------------- | ------------------------------- |
| We created a function to calculate the sum. | Chúng tôi tạo hàm để tính tổng. |
| This function takes two parameters.         | Hàm này nhận hai tham số.       |
| The function returns a number.              | Hàm trả về một số.              |

---

## 📚 Ví dụ minh họa

```javascript
function greet(name) {
  return "Hello, " + name + "!";
}

let message = greet("Linh");
console.log(message); // Hello, Linh!
```

---

## 🗣️ Phát âm luyện nói

* "function" → /ˈfʌŋkʃn/
* "parameter" → /pəˈræmɪtə(r)/
* "argument" → /ˈɑːɡjumənt/
* "return" → /rɪˈtɜːn/

---

## 💬 Hội thoại mẫu

> 👨‍💻 **A:** What does this function do?
> 👩‍💻 **B:** It returns the total price based on quantity and unit price.
> 👨‍💻 **A:** Nice. Can we reuse it elsewhere?
> 👩‍💻 **B:** Yes, just pass in different arguments.

---

## ✅ Bài tập nhanh

Điền từ còn thiếu:

1. A \_\_\_\_\_\_\_\_ is a block of reusable code.
2. \_\_\_\_\_\_\_\_ are passed to the function when you call it.
3. This function returns a \_\_\_\_\_\_\_\_.

> Đáp án: 1) function, 2) arguments, 3) value
