# 10 – **Bug**, **Debug** nghĩa là gì (English for Programmers)

## 🎯 Mục tiêu bài học

* Hiểu rõ nghĩa và cách dùng “bug”, “debug” trong môi trường lập trình
* Học từ vựng, cách phát âm, và ví dụ thực tế
* Dùng tiếng Anh để mô tả lỗi và quá trình sửa lỗi

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ | IPA                   | Nghĩa tiếng Việt   | Ghi chú thêm                           |
| ----------- | --------------------- | ------------------ | -------------------------------------- |
| bug         | /bʌɡ/                 | lỗi trong phần mềm | Có thể gây sai kết quả hoặc crash      |
| debug       | /ˌdiːˈbʌɡ/            | gỡ lỗi, sửa lỗi    | Quá trình tìm và sửa bug               |
| error       | /ˈerə(r)/             | lỗi (nói chung)    | Bao gồm cú pháp, logic, runtime error… |
| fix         | /fɪks/                | sửa chữa           | “Fix a bug” = sửa lỗi                  |
| issue       | /ˈɪʃuː/ hoặc /ˈɪsjuː/ | vấn đề             | Từ lịch sự hơn “bug” khi báo cáo       |
| crash       | /kræʃ/                | sập, treo          | Chương trình dừng đột ngột             |

---

## 🪲 Bug là gì?

* **Bug** là lỗi trong chương trình khiến kết quả sai hoặc ứng dụng hoạt động không đúng.
* Lỗi có thể do: cú pháp, logic, thiếu kiểm tra điều kiện, nhập sai…

📌 *Ví dụ:*

> "There is a bug in the login function – it doesn’t validate the password."

---

## 🔧 Debug là gì?

* **Debug** là quá trình tìm và sửa lỗi trong chương trình.
* Bao gồm: kiểm tra code, in log, dùng breakpoint, công cụ debug…

📌 *Ví dụ:*

> "I spent two hours debugging the payment module."

---

## 📚 Ví dụ minh họa

```javascript
function add(a, b) {
  return a - b; // ❌ Bug: dùng dấu '-' thay vì '+'
}

// Debug: phát hiện và sửa lại
function add(a, b) {
  return a + b; // ✅ Fixed
}
```

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                             | Dịch tiếng Việt                              |
| ----------------------------------------- | -------------------------------------------- |
| I found a bug in the checkout process.    | Tôi tìm thấy lỗi trong quá trình thanh toán. |
| Can you help me debug this function?      | Bạn có thể giúp tôi gỡ lỗi hàm này không?    |
| The app crashes when I click the button.  | Ứng dụng bị sập khi tôi nhấn nút.            |
| We need to fix this issue before release. | Ta cần sửa lỗi này trước khi phát hành.      |

## 🗣️ Phát âm luyện nói

* bug → /bʌɡ/

* error → /ˈerə(r)/
* issue → /ˈɪʃuː/
* crash → /kræʃ/
* fix → /fɪks/

---

## 💬 Hội thoại mẫu

> 👩‍💻 **A:** I think there’s a bug in the `register()` function.
> 👨‍💻 **B:** What’s wrong?
> 👩‍💻 **A:** It crashes when I input an empty email.
> 👨‍💻 **B:** Let’s debug it together.

---

## ✅ Bài tập nhanh

Điền từ còn thiếu:

1. I need to \_\_\_\_\_\_ this bug before the deadline.
2. The app \_\_\_\_\_\_ when loading large files.
3. We’re still \_\_\_\_\_\_ the issue with the login screen.

> **Đáp án:** 1) fix, 2) crashes, 3) debugging
