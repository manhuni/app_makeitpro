# C02 – Describing Features (Mô tả tính năng bằng tiếng Anh)

## 🎯 Mục tiêu bài học

* Học từ vựng và cấu trúc câu để mô tả **tính năng phần mềm**
* Giao tiếp hiệu quả khi viết tài liệu, trình bày, hoặc báo cáo
* Sử dụng tiếng Anh chuyên ngành rõ ràng, ngắn gọn

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ        | IPA              | Nghĩa tiếng Việt          | Ghi chú thêm                       |
| ------------------ | ---------------- | ------------------------- | ---------------------------------- |
| feature            | /ˈfiːtʃə(r)/     | tính năng                 | Phần chức năng cụ thể của sản phẩm |
| functionality      | /ˌfʌŋkʃəˈnæləti/ | chức năng                 | Cách hệ thống hoạt động            |
| allow (someone) to | /əˈlaʊ/          | cho phép ai làm gì        | Dùng khi nói về tác dụng           |
| enable             | /ɪˈneɪbl/        | kích hoạt, tạo điều kiện  | Trang trọng hơn “allow”            |
| user-friendly      | /ˌjuːzəˈfrɛndli/ | thân thiện với người dùng | Dễ sử dụng                         |
| customizable       | /ˌkʌstəˈmaɪzəbl/ | có thể tùy chỉnh          | Linh hoạt theo nhu cầu người dùng  |
| integration        | /ˌɪntɪˈɡreɪʃn/   | tích hợp                  | Ví dụ: Google Maps, PayPal, v.v.   |

---

## 🧠 Cấu trúc mô tả tính năng

| Cấu trúc câu                      | Ví dụ câu tiếng Anh                             | Dịch tiếng Việt                                          |
| --------------------------------- | ----------------------------------------------- | -------------------------------------------------------- |
| **This feature allows users to…** | This feature allows users to log in via Google. | Tính năng này cho phép người dùng đăng nhập bằng Google. |
| **It enables \[someone] to…**     | It enables admins to manage user roles.         | Nó giúp quản trị viên quản lý vai trò người dùng.        |
| **It is designed to…**            | It is designed to improve performance.          | Nó được thiết kế để cải thiện hiệu suất.                 |
| **The system supports…**          | The system supports real-time updates.          | Hệ thống hỗ trợ cập nhật theo thời gian thực.            |
| **Users can easily…**             | Users can easily customize their dashboard.     | Người dùng có thể dễ dàng tùy chỉnh giao diện.           |

---

## 📚 Ví dụ mô tả tính năng

> 🛒 **E-commerce App:**
> “This feature allows users to add items to their wishlist and receive price-drop notifications.”

> 🔐 **Security Module:**
> “It enables two-factor authentication for safer login.”

> 📆 **Calendar Tool:**
> “The system supports integration with Google Calendar and sends reminders automatically.”

## 💬 Hội thoại mẫu

> 👩‍💻 **A:** What features does the app have?
> 👨‍💻 **B:** It supports offline mode and allows users to save files locally.
> 👩‍💻 **A:** Is it customizable?
> 👨‍💻 **B:** Yes, users can change the layout and themes easily.

## ✅ Bài tập nhanh

Điền từ còn thiếu:

1. This feature \_\_\_\_\_\_ users to edit profiles.
2. The app is \_\_\_\_\_\_ and mobile-friendly.
3. It \_\_\_\_\_\_ real-time chat support.

> **Đáp án:** 1) allows, 2) customizable, 3) includes / supports
