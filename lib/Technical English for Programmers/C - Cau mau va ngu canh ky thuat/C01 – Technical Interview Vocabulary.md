# C01 – Technical Interview Vocabulary

## 🎯 Lesson Objective

Learn essential vocabulary, phrases, and expressions commonly used in **technical interviews** for software developers. This includes talking about experience, problem-solving, system design, and technical concepts in English.

## 🧠 Explaining a Solution

### 🔹 Phrases to Use:

* “The approach I used was a recursive algorithm.”
* “I chose a hash map for constant-time lookups.”
* “There’s a trade-off between speed and memory usage.”
* “This solution has a time complexity of O(n log n).”
* “I handled edge cases like empty input and large data sets.”

### 🔹 Explaining Logic (sample):

> “First, I sorted the input array. Then, I used a two-pointer technique to find pairs that sum to the target value. This reduces time complexity from O(n²) to O(n log n).”

---

## 📋 Common Technical Interview Questions (with Vocabulary)

1. **“Can you explain your thought process?”**
   → Trình bày logic giải quyết bài toán.

2. **“How would you optimize this?”**
   → Dùng từ như: *optimize*, *refactor*, *reduce complexity*

3. **“What are the trade-offs of your solution?”**
   → Nhắc đến hiệu suất (performance), chi phí (memory), độ dễ hiểu (readability)

4. **“How does your code handle edge cases?”**
   → Nêu rõ các trường hợp đặc biệt bạn đã xử lý.

5. **“Can you scale this system to handle millions of users?”**
   → Dùng từ như *scalability*, *load balancing*, *caching*, *database sharding*

## 🗣️ Speaking Practice

Practice saying:

* “I used a hash table to reduce the time complexity.”
* “One limitation of this solution is memory usage.”
* “If time allows, I’d write unit tests and improve error handling.”
* “This design allows for better scalability in production.”

**Choose the best term:**

1. You want to measure how fast an algorithm runs →
   a) Space complexity
   b) Time complexity ✅

2. Your system slows down under heavy traffic →
   a) Bottleneck ✅
   b) Concurrency

3. Your solution uses too much memory →
   a) Scalable
