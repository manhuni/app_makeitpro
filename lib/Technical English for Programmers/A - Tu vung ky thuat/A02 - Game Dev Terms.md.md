# A02 - Game Dev Terms

## 🎯 Lesson Objective

Learn and pronounce essential English terms used in **game development**, along with their Vietnamese meanings and practical usage.

---

## 🎮 What Is Game Development?

**Game development** is the process of creating a video game. It involves programming, art, design, sound, and testing.

Popular tools: **Unity**, **Unreal Engine**, **Godot**
Languages used: **C#**, **C++**, **GDScript**, **JavaScript**

---

## 🧩 Common Game Development Terms

| Term           | IPA Pronunciation   | Vietnamese Meaning            | Description (EN)                                              |
| -------------- | ------------------- | ----------------------------- | ------------------------------------------------------------- |
| game engine    | /ɡeɪm ˈɛn.dʒɪn/     | công cụ làm game              | Software used to build games (Unity, Unreal, etc.)            |
| frame rate     | /freɪm reɪt/        | tốc độ khung hình             | Number of frames per second (FPS)                             |
| asset          | /ˈæset/             | tài nguyên (ảnh, âm thanh...) | Any resource used in a game (images, sounds, 3D models...)    |
| sprite         | /spraɪt/            | hình ảnh 2D                   | A 2D image used for characters, objects, etc.                 |
| collider       | /kəˈlaɪ.dər/        | bộ va chạm                    | Detects physical collisions between objects                   |
| physics engine | /ˈfɪz.ɪks ˈɛn.dʒɪn/ | bộ xử lý vật lý               | Simulates real-world physics in the game                      |
| input          | /ˈɪn.pʊt/           | đầu vào                       | Player controls: keyboard, mouse, gamepad                     |
| animation      | /ˌæn.ɪˈmeɪ.ʃən/     | hoạt ảnh                      | Movement or visual changes of characters/objects              |
| level          | /ˈlev.əl/           | màn chơi, cấp độ              | A specific area or stage in a game                            |
| enemy          | /ˈen.ə.mi/          | kẻ địch                       | An AI-controlled character that opposes the player            |
| AI (A.I.)      | /ˌeɪˈaɪ/            | trí tuệ nhân tạo              | Behavior logic for non-player characters (NPCs)               |
| NPC            | /ˌen.piːˈsiː/       | nhân vật không điều khiển     | Non-playable character                                        |
| hitbox         | /ˈhɪt.bɒks/         | vùng va chạm                  | Area used to detect collisions (especially in fighting games) |
| camera         | /ˈkæm.rə/           | góc nhìn                      | Controls what the player sees on screen                       |
| render         | /ˈren.dər/          | hiển thị hình ảnh             | The process of drawing images to the screen                   |
| HUD            | /eɪtʃ.juːˈdiː/      | giao diện màn hình            | Heads-Up Display (e.g., score, health bar)                    |
| script         | /skrɪpt/            | mã điều khiển (script)        | Code that defines behavior in the game                        |
| spawn          | /spɔːn/             | sinh ra đối tượng             | Create an object (enemy, item, player) in the game world      |
| event          | /ɪˈvent/            | sự kiện                       | A triggered action (e.g., onClick, onCollision)               |
| update loop    | /ˈʌp.deɪt luːp/     | vòng lặp cập nhật             | Repeatedly called every frame to update game logic            |

## 🧠 Example in Context

```csharp
void Update() {
    if (Input.GetKeyDown(KeyCode.Space)) {
        Jump();
    }
}
```

### Translation:

* `Update()` – vòng lặp cập nhật
* `Input.GetKeyDown` – nhận đầu vào khi nhấn phím
* `KeyCode.Space` – phím cách
* `Jump()` – hành động nhảy
