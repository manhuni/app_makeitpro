# A01 - Programming Keywords

## 🎯 Lesson Objective

Learn and pronounce common programming keywords in English. Understand their Vietnamese meanings and usage in programming logic.

---

## 📘 What Are Keywords?

**Keywords** are reserved words in programming languages.
They **cannot** be used as variable names and have specific meanings for controlling the program flow and structure.

> Example: `if`, `else`, `for`, `while`, `return`, `import`, `class`

---

## 🔑 Common Programming Keywords

| Keyword    | IPA Pronunciation | Vietnamese Meaning | Description (EN)                         |
| ---------- | ----------------- | ------------------ | ---------------------------------------- |
| `if`       | /ɪf/              | nếu                | Executes a block if a condition is true  |
| `else`     | /els/             | ngược lại          | Executes if the `if` condition is false  |
| `for`      | /fɔːr/            | vòng lặp đếm       | Repeats a block a fixed number of times  |
| `while`    | /waɪl/            | trong khi          | Loops while a condition is true          |
| `break`    | /breɪk/           | thoát vòng lặp     | Exits a loop early                       |
| `continue` | /kənˈtɪn.juː/     | tiếp tục vòng lặp  | Skips to the next loop iteration         |
| `return`   | /rɪˈtɜːn/         | trả về             | Ends a function and sends back a value   |
| `def`      | /dɛf/             | định nghĩa hàm     | Defines a function in Python             |
| `function` | /ˈfʌŋk.ʃən/       | hàm (JS, C++)      | Declares a reusable block of code        |
| `class`    | /klɑːs/           | lớp                | Defines a class (OOP)                    |
| `import`   | /ˈɪm.pɔːt/        | nhập thư viện      | Loads external code modules              |
| `const`    | /kɒnst/           | hằng số            | Declares a constant value                |
| `let`      | /lɛt/             | khai báo biến      | Declares a block-scoped variable (JS)    |
| `var`      | /vɑːr/            | khai báo biến      | Declares a variable (older JavaScript)   |
| `try`      | /traɪ/            | thử                | Starts a block that might throw an error |
| `catch`    | /kætʃ/            | bắt lỗi            | Handles the error from `try`             |
| `finally`  | /ˈfaɪ.nəl.i/      | cuối cùng          | Runs after `try` and `catch`, always     |
| `switch`   | /swɪtʃ/           | lựa chọn           | Checks multiple possible cases           |
| `case`     | /keɪs/            | trường hợp cụ thể  | A condition inside a `switch`            |
| `default`  | /ˈdiː.fɔːlt/      | mặc định           | Code that runs if no `case` is matched   |
