# E02 – Viết lại bug report bằng tiếng Anh

---

## 🎯 Mục tiêu bài học

* Học cách viết bug report ngắn gọn, rõ ràng, chuyên nghiệp bằng tiếng Anh
* Biết các cấu trúc và từ vựng thường dùng trong báo cáo lỗi
* Luyện kỹ năng viết lại (rephrase) từ tiếng Việt sang tiếng Anh

---

## 📋 Cấu trúc cơ bản của bug report

| Phần                   | Nội dung                               |
| ---------------------- | -------------------------------------- |
| **Title**              | Tiêu đề lỗi, mô tả ngắn gọn            |
| **Environment**        | Môi trường: OS, trình duyệt, thiết bị… |
| **Steps to Reproduce** | Các bước để tái hiện lỗi               |
| **Expected Result**    | Kết quả mong đợi                       |
| **Actual Result**      | Kết quả thực tế                        |
| **Screenshots / Logs** | Ảnh chụp màn hình hoặc log nếu có      |

---

## 🧩 Từ vựng & Cấu trúc thường dùng

| Tiếng Anh                   | IPA                         | Tiếng Việt                    |
| --------------------------- | --------------------------- | ----------------------------- |
| bug / issue / defect        | /bʌɡ/, /ˈɪʃuː/              | lỗi                           |
| crash / freeze              | /kræʃ/, /friːz/             | sập / treo                    |

| severity / priority         | /sɪˈvɛrɪti/, /praɪˈɒrɪti/   | độ nghiêm trọng / mức ưu tiên |
| inconsistent behavior       | /ˌɪnkənˈsɪstənt bɪˈheɪvjər/ | hành vi không nhất quán       |
| cannot reproduce            | /ˈkænɒt ˌriːprəˈdjuːs/      | không thể tái hiện            |
| steps to reproduce          | /stɛps tuː ˌriːprəˈdjuːs/   | các bước để tái hiện lỗi      |
| actual vs expected behavior | /ˈækʧuəl vɜːs ɪkˈspɛktɪd/   | hành vi thực tế và mong đợi   |

## 📝 Mẫu bug report tiếng Anh

**Title:**
App crashes when clicking "Save" on the Profile page.

**Environment:**
iOS 16.3, iPhone 13, App version 2.1.4

**Steps to Reproduce:**

1. Open the app
2. Go to "Profile"
3. Tap "Edit"
4. Make any changes and tap "Save"

**Expected Result:**
Changes should be saved and user stays on the page.

**Actual Result:**
The app crashes and closes immediately.

---

## 🔄 Luyện viết lại từ tiếng Việt

### Câu gốc (tiếng Việt):

> Khi nhấn nút "Xác nhận" trong popup thì app bị đứng. Lỗi chỉ xảy ra trên Android 12.

### Viết lại (tiếng Anh):

> The app freezes when tapping "Confirm" in the popup.
> This issue only occurs on Android 12.

---

## 🧠 Mẹo viết chuyên nghiệp

✅ Sử dụng thì hiện tại đơn
✅ Mô tả chính xác, ngắn gọn, không cảm xúc
✅ Tránh dùng từ mơ hồ như "không chạy được", thay bằng mô tả cụ thể
✅ Nêu rõ môi trường để QA/dev có thể tái hiện

---

## ✍️ Bài tập nhanh

**Viết lại câu sau bằng tiếng Anh:**

> Khi chọn ảnh đại diện rồi nhấn Lưu, nhưng ảnh không thay đổi.

**Gợi ý viết lại:**

> After selecting a new avatar and tapping "Save", the image does not update.
