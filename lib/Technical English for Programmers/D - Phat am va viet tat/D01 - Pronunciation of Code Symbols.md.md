# D01 – Pronunciation of Code Symbols

## 🎯 Mục tiêu bài học

* Biết cách gọi tên các ký hiệu trong code bằng tiếng Anh chuẩn
* Dùng đúng trong hội thoại hoặc thuyết trình kỹ thuật
* Luyện phát âm và sử dụng trong ví dụ thực tế

---

## 🗣️ Ví dụ hội thoại

> 👩‍💻 **A:** How do you call `=>` in English?
> 👨‍💻 **B:** That’s called a “fat arrow”. It’s used in arrow functions in JavaScript.

> 👨‍💻 **A:** Should I use curly braces here?
> 👩‍💻 **B:** No, just parentheses are enough.
