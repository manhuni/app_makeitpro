# D03 – Common Mispronunciations in Tech

## 🎯 Mục tiêu bài học

* Nhận diện các từ kỹ thuật thường bị phát âm sai
* Biết phiên âm chuẩn quốc tế (IPA)
* Luyện nói bằng ví dụ thực tế

---

## 🔧 Từ thường bị phát âm sai

| Từ           | Phát âm sai phổ biến   | Phát âm đúng (IPA)               | Nghĩa / Ghi chú             |
| ------------ | ---------------------- | -------------------------------- | --------------------------- |
| **Linux**    | /ˈlaɪnʌks/             | /ˈlɪnəks/                        | Hệ điều hành mã nguồn mở    |
| **Java**     | /ˈdʒɑːvə/ *(UK)*       | /ˈdʒɑːvə/, /ˈdʒɑːvɑː/            | Ngôn ngữ lập trình          |
| **Git**      | /dʒɪt/, /ɡaɪt/         | /ɡɪt/                            | Hệ thống quản lý mã nguồn   |
| **Cache**    | /keɪʃ/, /kæʃe/         | /kæʃ/                            | Bộ nhớ đệm                  |
| **SQL**      | /skwəl/, /siːkwəl/     | /ˌes.kjuːˈel/ *(or)* /ˈsiːkwəl/  | Ngôn ngữ truy vấn dữ liệu   |
| **Debian**   | /ˈdebiən/              | /ˈdebiən/                        | Hệ điều hành dựa trên Linux |
| **Data**     | /ˈdɑːtə/               | /ˈdeɪtə/ *(US)*, /ˈdɑːtə/ *(UK)* | Dữ liệu                     |

---

## 📚 Ví dụ hội thoại

> 👨‍💻 **A:** I think your "cah-chee" is outdated.
> 👩‍💻 **B:** You mean the **cache** (/kæʃ/)? Let me clear it.

> 👩‍💻 **A:** I installed Apache on Debian yesterday.
> 👨‍💻 **B:** Nice! Did you run it as a **daemon**?

---

## 🗣️ Luyện nói – Reading Practice

```text
"I cleared the cache to fix the bug."
→ /aɪ klɪəd ðə kæʃ tuː fɪks ðə bʌɡ/

"Python uses indentation instead of braces."
→ /ˈpaɪθən ˈjuːzɪz ɪndɛnˈteɪʃən ɪnˈstɛd əv ˈbreɪsɪz/
```
