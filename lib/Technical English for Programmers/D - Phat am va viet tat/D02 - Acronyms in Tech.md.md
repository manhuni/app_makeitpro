# D02 – Acronyms in Tech

## 🎯 Mục tiêu bài học

* Ghi nhớ và phát âm đúng các từ viết tắt trong ngành IT
* Hiểu rõ ý nghĩa và cách sử dụng trong ngữ cảnh thực tế
* Sử dụng linh hoạt trong email, cuộc họp, phỏng vấn

---

## 🔠 What is an acronym?

> An **acronym** is a word formed from the first letters of other words.
> → **Từ viết tắt** là từ được tạo thành từ chữ cái đầu tiên của các từ khác.

Ví dụ:

* **API** = Application Programming Interface
* **IDE** = Integrated Development Environment

## 🧠 Mẹo học nhanh

* **Phát âm từng chữ cái** với các acronym như API, IDE, OOP
* **Phát âm như một từ riêng** với JSON, CRUD, REST, etc.

---

## 📚 Câu ví dụ

| Câu tiếng Anh                                        | Nghĩa tiếng Việt                                       |
| ---------------------------------------------------- | ------------------------------------------------------ |
| I built a REST API for the frontend to consume.      | Tôi đã xây dựng một API kiểu REST để frontend sử dụng. |
| This app uses a lot of RAM and CPU.                  | Ứng dụng này dùng rất nhiều RAM và CPU.                |
| You can test the API using a CLI tool like cURL.     | Bạn có thể test API bằng công cụ dòng lệnh như cURL.   |
| I'm working on the UI and UX of the web app.         | Tôi đang làm phần giao diện và trải nghiệm người dùng. |
| We need to write SQL queries to access the database. | Chúng ta cần viết truy vấn SQL để truy cập dữ liệu.    |
