# B01 - JIRA and Task Language

## 🎯 Lesson Objective

Learn essential English terms and phrases used in **task management systems** like JIRA, including how to describe, update, and communicate about tasks professionally.

---

## 📌 What Is JIRA?

**JIRA** is a popular issue-tracking and project management tool used by software teams to:

* Track bugs and features
* Assign tasks
* Monitor project progress
* Communicate clearly

---

## 🧩 Common Vocabulary in JIRA

| Term     | IPA Pronunciation         | Vietnamese Meaning   | Description (EN)                                                |
| -------- | ------------------------- | -------------------- | --------------------------------------------------------------- |
| issue    | /ˈɪʃ.uː/ or /ˈɪs.juː/     | công việc / lỗi      | Any task, bug, feature, or improvement                          |
| task     | /tæsk/                    | nhiệm vụ             | A single unit of work                                           |
| bug      | /bʌɡ/                     | lỗi phần mềm         | A flaw or malfunction in the software                           |
| epic     | /ˈep.ɪk/                  | đặc tả lớn           | A large body of work that can be broken down into smaller tasks |
| story    | /ˈstɔː.ri/                | người dùng cần gì    | A user-focused task that delivers value                         |
| sprint   | /sprɪnt/                  | vòng phát triển ngắn | A fixed period (1–2 weeks) for focused development              |
| backlog  | /ˈbæk.lɒɡ/                | tồn đọng             | A list of tasks/features waiting to be done                     |
| assign   | /əˈsaɪn/                  | giao việc            | To give someone a task                                          |
| status   | /ˈsteɪ.təs/ or /ˈstæ.təs/ | trạng thái           | Current stage of the task (To Do, In Progress, Done, etc.)      |
| priority | /praɪˈɒr.ə.ti/            | mức độ ưu tiên       | Importance level (High, Medium, Low)                            |
| label    | /ˈleɪ.bəl/                | nhãn                 | Tags to help categorize tasks                                   |
| comment  | /ˈkɒm.ent/                | bình luận            | Text added to give updates or request clarification             |
| update   | /ˈʌp.deɪt/                | cập nhật             | Inform others of the task’s current progress                    |
| resolve  | /rɪˈzɒlv/                 | xử lý / hoàn tất     | Mark an issue as completed or fixed                             |
| reopen   | /ˌriːˈəʊ.pən/             | mở lại               | Return a closed issue to active status                          |
| due date | /ˈdjuː deɪt/              | hạn chót             | Deadline for completing a task                                  |

## ✍️ Task Descriptions – Useful Phrases

| English Phrase                                  | Vietnamese Translation                         |
| ----------------------------------------------- | ---------------------------------------------- |
| This task is **blocked by** another issue.      | Nhiệm vụ này bị chặn bởi một vấn đề khác.      |
| The ticket is currently **in progress**.        | Thẻ này hiện đang được thực hiện.              |
| Please **assign** this to a frontend developer. | Vui lòng giao việc này cho lập trình viên FE.  |
| I’ve **updated the status** to "Ready for QA".  | Tôi đã cập nhật trạng thái là "Sẵn sàng test". |
| The bug was **resolved** in the latest build.   | Lỗi đã được xử lý trong bản build mới nhất.    |
| Let’s move this to the **next sprint**.         | Hãy chuyển việc này sang sprint tiếp theo.     |

## 🔧 Example Workflow

1. Create a **story**: "User can reset password via email"
2. Break it down into **tasks**: UI, backend API, validation
3. Assign tasks, estimate time
4. Add labels: `feature`, `security`
5. Track progress with statuses:

   * To Do → In Progress → In Review → Done

---

## 🗣️ Speaking Practice

Say these aloud:

* “Can you please update the status to In Review?”
* “I’ve added a comment explaining the bug.”
* “We should move this to the backlog.”
