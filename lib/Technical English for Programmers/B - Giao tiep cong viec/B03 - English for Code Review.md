# B03 - English for Code Review

## 🎯 Lesson Objective

Learn essential vocabulary, common expressions, and sentence structures used in **code review** discussions in English. This includes polite suggestions, constructive feedback, and asking for clarification.

## 🗣️ Useful Phrases for Code Review

### ✅ Giving Praise

* “Nice work on this function. It’s clean and well-structured.”
* “Good use of destructuring and modern syntax.”
* “This is a clever way to handle that edge case.”

### 🛠️ Suggesting Improvements

* “Consider renaming this variable to improve clarity.”
* “Could you simplify this logic for better readability?”
* “Is this function necessary, or could it be reused from another module?”
* “This part looks duplicated. Can we refactor it?”

### ❓ Asking for Clarification

* “Can you explain the purpose of this condition?”
* “What scenario does this `if` statement cover?”
* “Why are we using `any` here? Could we type it more strictly?”

### 📌 Requesting Changes

* “Please handle null/undefined values here.”
* “Let’s add some test coverage for this case.”
* “Missing error handling – can you include a fallback?”

---

## 🔁 Code Review Flow (Example)

1. Open a **Pull Request (PR)**
2. Reviewer reads the code and adds comments
3. Developer **responds**, **fixes**, or **discusses**
4. Reviewer **approves** or requests further changes
5. Code is **merged** after approval

---

## 🔤 Politeness in Review Comments

Avoid harsh or commanding language. Use softening phrases:

| Instead of...    | Use this instead...                      |
| ---------------- | ---------------------------------------- |
| “This is wrong.” | “I think there might be an issue here.”  |
| “Change this.”   | “Could you consider changing this to...” |
| “You forgot...”  | “Looks like this might be missing.”      |
| “Don’t do this.” | “An alternative approach might be...”    |

---

## 🎙️ Speaking Practice

Say these aloud:

* “Could you explain why we need this check?”
* “Let’s refactor this block to remove duplication.”
* “I’ve made the suggested changes. Please take another look.”
