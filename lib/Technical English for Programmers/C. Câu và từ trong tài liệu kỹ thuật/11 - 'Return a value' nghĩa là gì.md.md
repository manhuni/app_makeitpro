# 11 – "Return a value" nghĩa là gì?

## 🎯 Mục tiêu bài học

* Hiểu nghĩa và cách dùng của cụm “return a value”
* Biết cách giải thích bằng tiếng Anh khi nói về **hàm (function)**
* Luyện nói – nghe – hiểu tài liệu kỹ thuật dễ dàng hơn

---

## 🧩 Từ vựng chính (Key Vocabulary)

| Từ / Cụm từ          | IPA          | Nghĩa tiếng Việt | Ghi chú thêm                             |
| -------------------- | ------------ | ---------------- | ---------------------------------------- |
| return (v)           | /rɪˈtɜːn/    | trả về (giá trị) | Thường dùng trong hàm (function)         |
| value                | /ˈvæljuː/    | giá trị          | Có thể là số, chuỗi, mảng, đối tượng...  |
| function             | /ˈfʌŋkʃn/    | hàm              | Tập hợp các lệnh thực hiện một tác vụ    |
| output (n)           | /ˈaʊtpʊt/    | đầu ra           | Kết quả trả về của hàm hoặc chương trình |
| execute (v)          | /ˈeksɪkjuːt/ | thực thi         | “Run” một function                       |
| argument / parameter | /ˈɑːɡjumənt/ | đối số / tham số | Giá trị đưa vào hàm                      |

---

## 🔁 “Return a value” nghĩa là gì?

> Khi bạn **gọi một hàm**, hàm đó có thể **"return a value"** – tức là **trả về một kết quả** để bạn có thể sử dụng tiếp trong chương trình.

📌 Nghĩa tiếng Việt:
→ "Return a value" = "trả về một giá trị"

---

## 📚 Ví dụ trong lập trình

```javascript
function add(a, b) {
  return a + b;
}

let result = add(3, 4);  // result = 7
```

👉 Trong ví dụ trên:

* `add(3, 4)` **return a value** là `7`
* Giá trị đó được gán cho biến `result`

## 🔤 Câu mẫu (Example Sentences)

| Câu tiếng Anh                                                | Dịch tiếng Việt                                  |
| ------------------------------------------------------------ | ------------------------------------------------ |
| This function returns a value of type string.                | Hàm này trả về một giá trị kiểu chuỗi.           |
| If you don’t use `return`, the function returns `undefined`. | Nếu không dùng `return`, hàm trả về `undefined`. |
| We need to return the total price from this function.        | Chúng ta cần trả về tổng giá từ hàm này.         |
