# 13 – "Compile the code" nghĩa là gì?

## 🎯 Mục tiêu bài học

* Hiểu rõ cụm từ **“compile the code”**
* Biết cách giải thích bằng tiếng Anh
* Phân biệt với “run” và “interpret”
* Ứng dụng trong giao tiếp, tài liệu kỹ thuật

## ❓ "Compile the code" nghĩa là gì?

### ✅ Định nghĩa:

> **"Compile the code"** nghĩa là **biên dịch mã nguồn** sang mã máy mà máy tính có thể hiểu và chạy được.

Nói cách khác:

* Máy tính **không hiểu trực tiếp mã như Java, C++**
* Compiler sẽ **chuyển đổi** sang mã thấp hơn (machine code / bytecode)

---

## 📚 Ví dụ minh họa

### 💡 Ví dụ với C++:

```cpp
int main() {
  return 0;
}
```

➡ Khi bạn **compile** đoạn code trên, compiler sẽ tạo ra file thực thi `.exe` (Windows) hoặc không đuôi (Linux), sẵn sàng để chạy.

## 🔄 Phân biệt:

| Cụm từ             | Nghĩa tiếng Việt  | Ghi chú                                                  |
| ------------------ | ----------------- | -------------------------------------------------------- |
| compile the code   | biên dịch mã      | Giai đoạn chuyển mã nguồn thành mã máy                   |
| run the program    | chạy chương trình | Sau khi đã biên dịch thành công                          |
| interpret the code | thông dịch mã     | Chạy từng dòng mà không cần biên dịch trước (Python, JS) |
